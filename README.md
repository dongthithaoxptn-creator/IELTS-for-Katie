# IELTS Studio

A personal vocabulary and IELTS practice app for MacBook, iPad and phone. It is plain HTML, CSS and JavaScript, with no build step and no server.

- **Vocabulary**: word-family trees with British IPA and Vietnamese meanings, B2+ phrasal verbs and collocations, spaced repetition, and a daily test of at least 10 learned words each time you open the app.
- **Reading, Listening, Writing, Speaking**: exam-style practice. Tap any word in a passage to see a dictionary card.
- **AI marking** for Writing and Speaking against the official IELTS band descriptors. You add your own Claude API key in Settings; it is stored only on your device.
- **Progress**: estimated band per skill and overall, trends, study time and streak.

## Listening books
No book audio or book pages are included in this repository. The Listening section works with book packs (`cam16.zip` … `cam20.zip`) that you import on each device in **Settings → Cambridge books on this device**. The packs stay in that device's browser storage and are never uploaded.

## Install on iPad
1. Open the site in Safari, then tap Share → **Add to Home Screen**.
2. Open IELTS Studio **from the Home Screen icon**, go to Settings, and import your book packs from the Files app.
